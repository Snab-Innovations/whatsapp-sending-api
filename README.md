# WhatsApp Web Chat Viewer (Node.js + React)

A full-stack application built with **Node.js (Express + `whatsapp-web.js`)** and **React (Vite + Tailwind CSS)** that connects to WhatsApp via headless Chrome (Puppeteer), authenticates with dynamic QR code scanning, persists authentication locally (`.wwebjs_auth`), and fetches all chats and messages into a modern web interface.

---

## 🚀 Quick Start Guide

### Step 1: Start Node.js Backend Server

```bash
cd server
npm start
```
*The server starts on `http://localhost:5001` and initializes Puppeteer with `LocalAuth` session persistence.*

### Step 2: Start React Frontend App

In a separate terminal window:

```bash
cd client
npm run dev
```
*The React web app opens at `http://localhost:5173`.*

---

## 📱 How to Use

1. **Scan QR Code**:
   - Open `http://localhost:5173` in your browser.
   - The app will dynamically display the QR code generated by `whatsapp-web.js`.
   - Open WhatsApp on your phone → **Menu ⚙️ / Settings** → **Linked Devices** → **Link a Device** and scan the QR code.
2. **Session Persistence**:
   - Once scanned, the session is saved locally in `server/.wwebjs_auth`.
   - You **do not** need to scan the QR code again when restarting the application.
3. **Explore Chats & Messages**:
   - Filter chats (All, Unread, Groups) or search contacts by name/number.
   - Select any chat to view full conversation history with real-time timestamps.
   - Compose and send messages directly from the React interface.
4. **Logout / Re-scan**:
   - Click the **LogOut** button in the header to purge local session files and request a new QR code.
